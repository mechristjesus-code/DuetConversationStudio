# Contributing to Duet Conversation Studio

Thank you for your interest in contributing to Duet Conversation Studio!

## Development Workflow
1. Fork the repository and create your branch from `master`.
2. Open the project in **GitHub Codespaces** or locally via Termux (`./start-studio.sh`).
3. Run the test suite to ensure everything is passing:
   ```bash
   python3 backend/test_studio.py
   ```
4. Submit a Pull Request referencing any related issues.
